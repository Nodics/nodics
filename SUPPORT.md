# Support Policy

Nodics is source-available commercial software. Source access does not include a right to resell, white-label, host as a managed service, or productize Nodics-based applications for third parties without a separate Nodics commercial/support agreement.

## Support model

Supported use is governed by the active license and written support agreement. Support scope may include:

- framework upgrade guidance;
- security triage;
- release validation;
- production-readiness review;
- custom-module design review;
- provider integration guidance;
- migration and compatibility planning.

Community or evaluation use is best-effort and does not include production SLA, emergency response, or resale/productization rights.

## What to include in a support request

- repository branch and commit;
- environment, server, and node context;
- active modules;
- relevant schema, route, service, provider, or generated artifact;
- exact command or API request;
- logs with secrets removed;
- expected business outcome and actual behavior.
