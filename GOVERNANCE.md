# Repository Governance

This repository is governed as the Nodics framework source. It is backend/API framework authority; clients such as Nodics Axis, websites, and other BackOffice experiences are separate workstreams.

## Governance sources

- `LICENSE` owns legal permission.
- `AGENTS.md` owns AI/developer working instructions.
- `README.md` explains framework purpose and capabilities.
- `gSetup/llm` owns durable AI/tooling standards and implementation contracts.
- Root policy documents own repository-level contribution, security, release, support, compatibility, deprecation, versioning, and incident-response expectations.
- Module `README.md` files explain module intent and customization surface.

## External adoption gate

Before broader external adoption, Nodics must have:

- source-available commercial license boundaries;
- private vulnerability reporting;
- contribution rules;
- support policy;
- clean release workflow;
- compatibility and deprecation policy;
- versioning policy;
- incident-response process;
- tests proving these governance files remain present and meaningful.
