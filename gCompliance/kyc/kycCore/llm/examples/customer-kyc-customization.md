# Customer KYC customization

Override only the smallest effective policy or named implementation in a later project/customer module. Preserve scoped identifiers, exact commercial thresholds, explicit intent APIs, private nMedia references, immutable decisions, Workflow ownership, provider normalization, and audit. Focused tests must resolve the effective customer configuration rather than asserting framework defaults.

Never copy KYC schemas, provider registries, Pipelines, Workflows, or Axis navigation merely to rename a label or change one threshold. Rollback removes the later-layer contribution; it does not mutate historic evidence.
